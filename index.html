pokedex-secure

A deliberately security-conscious Pokedex lookup over the public PokeAPI. The point is not the Pokedex, it is the engineering discipline around it: validate input before it ever reaches a URL, keep the request safe, and fail without leaking internals.

Security controls in this lookup

  • Allow-list validation before any request: ^[a-z0-9-]{1,50}$ (blocks injection / SSRF-style input).
  • Fixed API host — user input can never redirect the request elsewhere.
  • Safe failure — 404 and network errors show a friendly message, never a stack trace or internal URL.
  • No secrets, no tracking — the request goes only to PokeAPI; nothing else leaves your browser.
The Python CLI in this repo enforces the same controls, with unit tests, bandit (SAST), pip-audit and gitleaks in CI.
